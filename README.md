# Rocha Origin

**Rocha Origin** is an internal operations and order management system developed for Talho Rocha.  
It centralizes B2B order registration, preparation workflow, route organization, and weight adjustments for accurate invoicing, while laying the foundation for full meat traceability at animal, lot, and piece level.

---

## 🚀 Overview

Rocha Origin is designed as the operational backbone of Talho Rocha.  
The system supports daily order management and production workflows, with a scalable architecture prepared for future integration with traceability platforms such as **Meat Azores**.

The project follows a phased development approach, starting with core operational functionality (MVP) and progressively expanding into full origin transparency.

---

## ✅ Core Features (MVP)

- Team authentication (Admin, Sales, Butchery roles)
- B2B client and establishment management
- Order creation and editing
- Route assignment and filtering
- Order status workflow:
  - `PENDING`
  - `PREPARING`
  - `IN_TRANSIT`
  - `DELIVERED`
- Real weight adjustment during preparation
- Operational dashboard for daily production control

---

## 🔜 Planned Features (Post-MVP)

- Supplier management
- Animal registration with EUROP classification
- Automatic weekly lot generation
- Traceable piece generation with unique identifiers
- QR code labels for end-customer transparency
- Integration with Meat Azores
- Label printing system (internal and customer-facing)
